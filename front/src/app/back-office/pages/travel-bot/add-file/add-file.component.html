Knowledge Base File Operations

File path is required.

Loading a file: This will add all entries from the file to the knowledge base.

Make sure your file has the correct format:

  • JSON: Array of objects with "Question" and "Response" fields
  • CSV/Excel: Spreadsheet with "Question" and "Response" columns

Saving to a file: This will save the entire knowledge base to the specified file.
